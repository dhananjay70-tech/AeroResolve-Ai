PHASE 2 — AUTHENTICATION
==================================================

Implement customer authentication using:

- Email + password
- bcryptjs for password hashing
- JWT for authentication
- HTTP Authorization header using Bearer tokens
- JWT secret stored only in .env
- Never store plain-text passwords
- Never expose password hashes through APIs

Install if required:

npm install bcryptjs jsonwebtoken
npm install -D @types...  <-- DO NOT install TypeScript types because this project is JavaScript only.

Authentication endpoints:

POST /api/auth/register
POST /api/auth/login
GET  /api/auth/me

Register flow:

1. Validate email and password using Zod.
2. Check whether email already exists.
3. Hash password using bcrypt.
4. Create user in PostgreSQL.
5. Generate JWT.
6. Return safe user information and token.
7. Never return password or password hash.

Login flow:

1. Validate email/password.
2. Find user by email.
3. Compare password using bcrypt.
4. Generate JWT.
5. Return token and safe user information.
6. Return a proper 401 response for invalid credentials.

GET /api/auth/me:

1. Read Bearer token.
2. Verify JWT.
3. Get user from database.
4. Return authenticated user.

Create authMiddleware.js:

- Read Authorization header.
- Verify Bearer JWT.
- Attach authenticated user ID to req.user.
- Reject missing/invalid/expired tokens with HTTP 401.

PHASE 6 — BUSINESS LOGIC
==================================================

Create policyService.js.

Do NOT allow Gemini or an LLM to invent policy decisions.

The backend policy/business logic must enforce the assignment rules.

The policy engine must support:

1. Airline cancellation:
   - Free rebooking on next available flight within 24 hours
   - OR full refund
   - Customer chooses.

2. Delay under 3 hours:
   - ₹500 meal voucher.

3. Delay more than 3 hours:
   - Meal voucher
   - Lounge access.

4. Delay more than 5 hours:
   - Meal voucher
   - Lounge access
   - Hotel accommodation covering delayed hours only.
   - Not a full night's stay.

5. Airline-caused cancellation refund:
   - Full refund.
   - Original payment method only.
   - Processing within 7 business days.

6. Voluntary higher-fare rebooking:
   - Customer pays fare difference.
   - Fare difference above ₹1,500 cannot be waived by the agent.
   - Escalate for supervisor approval.

7. Gold and Platinum:
   - Priority rebooking.
   - No additional compensation beyond standard policy.

Prohibited actions must trigger escalation:

- Compensation beyond stated policy.
- Waiving fare difference above ₹1,500.
- Exceptions for non-airline-caused disruptions.
- Legal threats/formal complaints.
- Refund to a different payment method.
