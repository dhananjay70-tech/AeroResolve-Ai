==================================================
GOAL
==================================================

Add a real outbound supervisor escalation calling capability.

The workflow should be:

Customer talks to AeroResolve AI Agent
        ↓
AI Agent attempts to resolve the customer's issue
        ↓
Customer requests a manager OR backend determines escalation is required
        ↓
AI Agent creates a real escalation
        ↓
Backend starts an outbound supervisor call
        ↓
Supervisor/manager's Indian +91 phone rings
        ↓
AI voice agent explains the escalated case
        ↓
Supervisor can respond
        ↓
Call result/status is recorded
        ↓
AeroResolve UI displays the call/escalation status

This should feel like a real AI agent performing a human handoff.

1. VOICE PROVIDER
==================================================

Use an India-focused voice provider that supports outbound Indian domestic calling.

Prefer Exotel for the initial implementation.

Before implementing provider-specific code:

Inspect the current project and identify the cleanest integration point.

Do not assume credentials or account configuration already exist.

If the provider credentials/configuration are missing, implement the integration safely with clear environment-variable placeholders and a graceful "voice service not configured" response.

Do NOT fake a successful call.

4. ESCALATION FLOW
==================================================

When the AI agent determines that supervisor involvement is required:

1. Create the normal AeroResolve escalation using the existing escalation API/service.
2. Store the escalation ID.
3. Create an outbound supervisor call.
4. Associate the call with the escalation.
5. Return structured call status to the frontend.

Example:

{
  "escalationId": "...",
  "callStatus": "initiating",
  "message": "Supervisor call is being initiated."
}

Do not create duplicate escalation records.

Do not create duplicate calls if the same escalation already has an active call.
